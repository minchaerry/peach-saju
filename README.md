# 도화 연애사주 (桃花)

생년월일과 태어난 시간으로 사주를 세우고, **연애**에 집중해서 풀어 주는 웹 서비스예요.
서버 없이 브라우저에서만 돌아가는 HTML 파일 한 개로 되어 있어요.

> 오락·참고용 서비스예요. 풀이 결과는 의학, 법률, 투자 같은 중요한 결정의 근거가 될 수 없어요.

## 주요 기능

- **단계형 입력 플로우**: 한 화면에 질문 하나씩 나와요.
  - 고민 선택 (짝사랑 · 썸 · 연애중 · 관계 위기 · 이별 후 · 재회 · 새 인연)
  - 고민별 상황 질문
  - 호칭·성별, 생년월일(양력), 태어난 시간(정확히 / 시진 / 모름), 출생 지역
  - 상대 생일 (건너뛸 수 있음)
  - 듣고 싶은 한마디, 확인·동의
  - 명식 세우는 연출
- **내 사주 탭**: 원국 8글자, 오행, 십성, 도화살·홍염살, 연애 패턴, 대운·세운
- **고민별 처방**: 고민마다 다른 풀이와 직언(듣기 싫지만 사실)
- **궁합 탭**: 두 사람의 케미 지수, 상대의 호감 신호, 관계 구조에서 나오는 직언
- **그 사람과의 30일 달력**
  - 다음 좋은 날 D-day 표시
  - 날짜를 누르면 그날 할 일과 근거
  - 좋은 날에는 그날 보낼 문장을 복사할 수 있고, "다른 문장" 버튼으로 바꿀 수 있어요.
  - 이번 주 7일은 무료, 나머지는 잠금 (결제 연결 전 미리보기)
- **궁금한 거 바로 물어보기**: 질문을 입력하면 내 사주를 바탕으로 답해 줘요.
- **공유 링크**: 결과 주소(`#r-...`)를 공유하면 같은 결과가 열려요.

## 실행하는 법

`index.html`을 브라우저로 열면 바로 실행돼요. 빌드나 설치가 필요 없어요.

## GitHub Pages로 배포하기

1. 이 폴더의 파일을 GitHub 저장소 루트에 올려요.
2. 저장소의 **Settings → Pages**로 가요.
3. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 정하고 저장해요.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열려요.

`.nojekyll` 파일은 GitHub Pages가 파일을 그대로 서비스하게 하려고 넣어 둔 빈 파일이에요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 서비스 전체 (화면, 스타일, 사주 계산 엔진, 풀이 문구) |
| `README.md` | 이 설명서 |
| `.nojekyll` | GitHub Pages 설정용 빈 파일 |
| `.gitignore` | 올리지 않을 파일 목록 |

## 데이터와 개인정보

- 입력값은 서버로 보내지 않아요. 브라우저 안에서만 계산해요.
- 다시 볼 때 편하도록, 입력한 내용은 그 기기의 브라우저 저장소(localStorage)에만 남겨요.
- 외부에서 불러오는 건 Google Fonts(Noto Sans KR, Noto Serif KR)뿐이에요.
